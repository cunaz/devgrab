# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability
reporting: https://github.com/cunaz/devgrab/security/advisories/new (the
repository's *Security* tab). You should hear back within a week.

## What counts

DevGrab runs entirely inside Firefox: no server, no accounts, no data
collection. Reports that matter are about the extension itself, for example a
web page that makes the extension write outside the archive folder, run page
content with extension privileges, or request access it should not have.

## Supported versions

Fixes go into the latest release only.
